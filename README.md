# Seasonal Agriculture Performance Analysis

VOIS AICTE Major Project — Batch 1, 2026-2027

## Overview
This project analyzes agricultural performance data across three Indian cropping seasons — Kharif, Rabi, and Zaid — to identify patterns, trends, and differences in yield, profitability, resource usage, and environmental conditions.

## Dataset
`seasonal_agriculture_performance_dataset.csv` — 4,000 farm records across 8 Indian states and 8 crops, covering farming practices, environmental conditions, resource usage, and economic outcomes.

## Objective
To analyze how agricultural performance varies across seasons and provide data-driven insights and recommendations for seasonal agricultural planning.

## Approach
- Data cleaning and preparation
- Season-wise comparison of yield, profit, and resource usage
- Correlation analysis between environmental factors and yield
- Irrigation method efficiency comparison
- Crop-wise performance across seasons
- Statistical significance testing (ANOVA)
- Insights and recommendations based on findings

## Tools Used
Python, Pandas, NumPy, Matplotlib, Seaborn, SciPy — run on Google Colab

## Files
- `Seasonal_Agriculture_Performance_Analysis_2.ipynb` — full analysis notebook
- `seasonal_agriculture_performance_dataset.csv` — dataset used
